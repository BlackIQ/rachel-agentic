# Rachel Frontend

NextJs user interface for the **Rachel** API.

## Stack

- **TypeScript**: 💙
- **NextJs**: Frontend framework
- **React**: React
- **MUI**: Design stuff

## Setup

First go inside directory:

```bash
cd frontend
```

Install packages:

```bash
npm install
```

### Configure `.env`

Copy `.env.example` to `.env.local`:

```bash
cp .env.example .env.local
```

So, now edit it:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

### Run

Just:

```bash
npm run dev
```

- UI: `http://127.0.0.1:3000`
